# APPS-LOADER COMPACT MAP

## 1. Project & Status
- **What**: Self-hosted platform to host static HTML apps (`/sites/<slug>/`), in-browser code editor ("Fiddle"), and bookmark hub with a PIN-protected vault.
- **Stack**: Node.js (ESM), Express 5, `better-sqlite3` (WAL), `keyv` (cache), JWT auth (`httpOnly` cookie), EJS, Tailwind CSS v4, DaisyUI 5.
- **Status**: Operational, fast precompiled CSS (zero CDN lag), port persisted in `port.txt`.

## 2. File-to-Feature Map
| Feature / Area | Core File(s) |
|---|---|
| **Server & Routing** | `src/server.js` (entry point, route handlers, error logging, port auto-select) |

## 3. Key Notes & Optimizations
- **Speed**: Eliminated slow CDN scripts (`cdn.tailwindcss.com`, unpkg); everything is bundled in local `public/style.css` (70KB minified).
- **Guidelines**: Pure ES6 functions (no classes), native `fetch`, `type="module"`, error logging enabled.
- **Features added**: `deleteApp` route & UI, fixed `isProtected` bookmarks, fixed cache invalidation, Fiddle safe JSON prefill, Clear All editor button, Smart Tag Split, Combined all-in-one code tab, Copy All standalone code, zero-reload in-place save, live public site link, synchronized line numbers gutter, comment toggler (Ctrl+/), auto-indent & bracket pairs, responsive viewport switcher, and interactive console drawer.
